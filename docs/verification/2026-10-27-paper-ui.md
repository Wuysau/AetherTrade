# PAPER state presentation

The console now separates target quantity, in-flight quantity, actual position,
verified protection and active risk locks. Request receipt status is checked
explicitly; PENDING, SUBMITTED, UNKNOWN and missing status never announce a fill.
Only a reported verified protection state displays a verified quantity. Existing
orders without provenance are labeled historical local simulation records.

This report is presentation evidence, not unified execution qualification.
