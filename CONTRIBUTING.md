# Contributing

Thank you for your interest. This project uses documented architecture contracts, task IDs, isolated worktrees, and independent review evidence.

- Keep the approved architecture and trading safety invariants intact. Propose contract changes explicitly.
- Do not submit exchange credentials, actual account records, production logs, personal financial data, private keys, or paid model access tokens.
- Do not enable LIVE trading in examples, CI or PRs. Use fictional PAPER data.
- Document tests executed, tests not executed, and the exact code commit tested. Never call a mocked scenario real exchange qualification.
- Prefer focused PRs; do not mix shared manifests and contract changes from independent worktrees without coordination.

Open an issue first for security-critical changes or changes to execution architecture.
