# Security Policy

This project is not authorized for real-money trading by default.

## Reporting vulnerabilities

Please do not include API keys, exchange account details, trade exports, wallet private keys, seed phrases, or production infrastructure details in public issues, PRs, or comments.

If private vulnerability reporting is enabled, use the repository's **Security → Report a vulnerability** flow. Otherwise contact the maintainer privately through an established channel instead of posting exploit details publicly.

## Supported scope

Until an explicit released/qualified product exists, no deployment is certified or supported for live funds. If you discover a way to bypass the execution-owner permission boundary, treat it as a sensitive security issue.
