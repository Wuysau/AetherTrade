# Agentic Trading System

Open-source, research-oriented architecture for an AI-assisted automated trading system.

**Status:** architecture approved; implementation and market qualification are not complete.
**Safety:** paper-mode by default; no real-money trading is enabled by this repository.

Intended capabilities: AI-directed decisions, deterministic rules, hybrid strategies, Binance spot / USD-M futures / eligible US stocks, a single risk and execution owner, auditable order and position recovery, mobile Web and terminal controls.

Important: this project is software research, not financial advice. Trading carries the risk of financial loss, including losses exceeding planned thresholds for leveraged products. Never give a development process a production trading key.
